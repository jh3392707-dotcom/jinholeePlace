# 🧒 재민이 키우기

7살 재민이를 80살까지 키우는 선택형 인생 시뮬레이션. 직업·연봉을 정하고 최종 인생 점수(S~F)로 평가받는다.

- 실행: `index.html`을 브라우저로 열면 끝 (설치/서버 불필요, 한 판 약 15~25분)
- 참고: kickru.com "벤치에서 발롱까지"의 흐름(후보 선택 → 시즌 진행+선택 사건 → 은퇴 후 인생 정리·랭킹·자동저장)을 인생 시뮬레이션으로 옮김

## 추가된 재미 요소 55가지

1. 시작 후보 3명 중 선택(스타일별 능력 분배)
2. 집중 육성 능력치 2개
3. 태어난 집안(금수저/평범/흙수저)
4. 숨은 재능 7종(천재, 강골, 행운아 등)
5. 오늘의 운세(날짜별 확률 보정)
6. 난이도 3종(힐링/보통/지옥)
7. 환생 포인트로 능력치 보너스
8. 7~80세 나이별 아바타 변화
9. 시즌(해)마다 스트레스·행복 자동 변동
10. 확률 도전 선택지(성공률 표시)
11. 능력치에 따른 성공률 보정
12. 학원/동아리/연애 등 성장기 이벤트 15종
13. 수능 결과 → 대학 선택 → 재수
14. 군대 이벤트(카투사 도전)
15. 직업 16종 + 능력·학력 요건 잠금

17. 정기 연봉 협상(성과/이직 카드)
18. 승진 심사와 직급 체계
19. 이직 제안
20. 갑질 상사/구조조정
21. 가변 소득 직업(유튜버·연예인·창업가 등)
22. 운동선수 전성기·은퇴 기로
23. 부업 이벤트
24. 주식/코인 투자(변동성 시뮬)

# 재민이 키우기 — 꼭 알아두실 사항

## 1. 해주셔야 할 것
| 순서 | 할 일 | 방법 |
|---|---|---|
| 1 | 레벨업 소리 | 나이 먹을 때 쓸 소리를 **mp3 파일**로 올려 주세요(유튜브 링크는 내려받을 수 없음). `assets/sfx/levelup.mp3`로 넣으면 적용 |
| 2 | BGM 배치 확인 | 곡 이름을 몰라서 업로드 순서·길이로 구간을 정했어요. 들어 보고 어색한 구간을 알려 주세요 |
| 3 | 찬호 얼굴 허락 | 찬호 얼굴이 미니게임에 나와요. 링크가 퍼지기 전에 본인에게 말해 두세요 |
| 4 | 결혼·자녀 루트 | 거의 안 열려요(800판 중 결혼 3번). 청혼 비용 3000만→1000만 원으로 낮출지 정해 주세요 |
| 5 | (선택) AI 장면 이미지 | `docs/AI_SCENE_GUIDE.md` 참고. 안 만들어도 게임은 정상 동작 |

## 2. 저작권·초상권
- **음원:** 메이플스토리·서든어택·피파온라인3 곡은 저작권이 있어요. 친구들끼리 링크로 공유하는 정도로만 쓰세요. 블로그·SNS 등 공개 게시는 피하세요.
- **얼굴:** 재민이·찬호 얼굴이 게임과 공유 이미지 카드에 들어가요. 다른 친구 얼굴은 쓰지 않았어요.
- 팝업 광고는 모두 **가상 광고**(문구 표시됨)예요. 실제 상품이 아니에요.

## 3. 공유 링크(아티팩트) 관련
- **용량:** BGM 포함 약 23MB. 아티팩트 한도(전체 256MB, 파일당 15MB) 안이라 올라가지만, 처음 열 때 느릴 수 있어요. 폰에서 한 번 열어 확인하세요.
- **소리:** 열자마자 BGM 자동재생을 시도해요. 브라우저가 막으면(폰은 거의 항상) "터치해서 시작" 화면이 뜨고, 터치하는 순간 BGM이 시작돼요. 폰 무음 모드면 안 들릴 수 있어요.
- **저장:** 공유 이미지 카드의 "저장" 버튼은 아티팩트 안에서 막힐 수 있어요. **이미지를 길게 눌러 저장**하거나 공유하기를 쓰세요.
- **아티팩트 수정:** 저는 같은 링크에 덮어써서 갱신해요. 링크는 바뀌지 않아요.

## 4. 게임 동작 참고
- **화면은 밝은 모드 고정**이에요(어두운 모드 버튼 제거).
- **군 복무 중**에는 재민이가 군복+전투모를 입고, 전역하면 원래 옷으로 돌아와요. 경찰 직업은 경찰모를 써요.
- 난이도는 하드 고정, 성공 확률이 낮은 게 정상이에요(대부분 불리한 출발 80%).
- **캐릭터 만들기:** 주사위 최대 5번. 이름 CHECK는 입력 여부만 확인해요(중복 검사 아님).
- **돌발 이벤트(🚨 돌발 이벤트 출현! 연출):** 일본 지하철 낙오(27세) → 진호의 분노(여행 3일 전), 찬호 가게 "인생은 아름다워라"(29세~ 매주 호출, 10만 원 강제 계산), 미니게임 4종
- **미니게임은 무조건 진행:** 선택지 2개 중 어느 쪽을 골라도 자연스러운 멘트(찬호·경연이 막아서는 장면)와 함께 미니게임으로 이어져요.
- **미니게임 4종 (판당 1번씩):**
  - 17세 「수업 중 경연이 몰래 방구」— 어려움. 버튼을 누르는 동안 방구, 선생님이 뒤돌아보면 손 떼기(자는 척). 3번 들키면 실패. 들키면 최다인·임유미가 "야!! 임재민!!! 방구좀 작작껴!!!"
  - 15세 전후 「미역국에 꿀떡 풍덩 막기」— 난이도 극악. 못 막으면 재민이가 맛있게 냠냠 먹는 연출
  - 36세 전후 「찬호의 날달걀 폭격」— 난이도 극악. 맞든 피하든 결국 재민이가 전부 맛있게 먹는 결말
  - 30세 전후 「찬호의 물건 던지기」— 오이고추·비치발리볼·소시지 피하기
  - 조작: 화면을 손가락으로 끌기 / 마우스 / ← → 키. 미니게임 BGM은 `dodge.mp3` 공용
- **팝업 광고:** 24·46·68세에 한 번씩. ✕는 즉시, 건너뛰기는 3초 후. 미니게임·게이지 중에는 뜨지 않아요.
- **저장:** 자동저장은 브라우저(localStorage)에 해요. 시크릿 모드·다른 기기에서는 이어하기가 안 돼요. 저장 파일 내보내기/불러오기를 쓰면 옮길 수 있어요.

## 5. 알려진 한계
- 도트 얼굴은 정면 사진이 5장뿐이라 일부가 기울어져 있어요. 정면 사진을 더 주시면 개선돼요.
- 찬호 얼굴은 원본이 양옆이 잘려 좁고 길게 나와요.
- 도트 몸은 코드로 그린 거라 손으로 찍은 도트만큼 섬세하진 않아요.
- 개발용 점검 스크립트의 "점수 이상 …D" 경고는 D등급을 이상으로 오인하는 옛 검사식 때문이며 실제 오류가 아니에요.

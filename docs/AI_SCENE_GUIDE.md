# 재민이 AI 장면 이미지 제작 가이드

재민이 사진을 AI로 다양한 상황·직업·나이의 재민이로 바꿔서, 게임 곳곳에 넣기 위한 준비 문서예요.
게임은 이미 **이미지 파일 이름만 맞춰 넣으면 자동으로 가져다 쓰도록** 만들어져 있어요.

---

## 0. 오늘 저녁 할 일 (요약)

1. **기준 사진 고르기** (3~6장): 이미 있는 `assets/face.jpg`, `main.jpg`, `joy.jpg`, `cool.jpg`, `hike.jpg`, `tired.jpg`와 원본 사진.
2. **스타일 하나 정하기**: 모든 이미지가 같은 그림체여야 게임이 일관돼 보여요. (아래 3번 참고)
3. **캐릭터 기준 시트 1장 만들기**: 정면, 옆모습, 웃는 얼굴이 한 장에 나오는 기준 이미지.
4. **우선순위 1번 24장** 만들기: 시작 화면, 나이 3, 직업 15, 엔딩 5.
5. **우선순위 2번 26장** 만들기: 오이, 비치볼, 소시지, 달걀 같은 대표 사건들.
6. 파일을 `assets/scenes_raw/`에 넣고 `python3 tools/prepare_scenes.py` 실행 → 커밋/푸시 → "이미지 올렸어, 아티팩트에도 반영해 줘"라고 알려 주기.

> 시작 화면은 지금 **"비치볼에 맞는 재민이"** 애니메이션(재민이 사진 + 날아와서 퍽! 맞는 비치볼)이 들어가 있어요.
> `lobby_beachball` 이미지를 넣으면 그 이미지로 자동 교체돼요.

## 2. 시작 전에 꼭 확인할 것

**동의와 안전**
- 변환할 사진은 **재민이 혼자 나온 사진**만 쓰세요. 친구 얼굴이 나온 사진을 AI에 올려 변환하는 건 본인 동의가 있을 때만 하세요.
- 친구가 나오는 장면(진호, 찬호, 경연 등)은 **재민이만 그리고 친구는 뒷모습·실루엣·일러스트로** 하거나, 본인에게 먼저 물어보세요.
- 이 게임은 링크로 공유돼요. 이미지에 **집 주소, 학교 이름, 자동차 번호판, 전화번호**가 나오지 않게 하세요.
- AI 서비스는 올린 사진을 학습에 쓸 수 있어요. 올리기 전에 서비스의 **데이터 사용/학습 설정**을 확인하세요.

**만들지 않을 것 (제작 비권장 12개)**

## 3. 도구 선택

아래는 일반적인 특징이에요. 기능 이름과 제공 범위는 자주 바뀌니, 쓰기 전에 현재 기능을 확인하세요.

| 도구 | 장점 | 주의 |
|---|---|---|
| ChatGPT 이미지 생성/편집 | 사진을 올리고 대화로 계속 고칠 수 있음. 같은 대화 안에서 일관성 유지가 쉬움 | 대화가 길어지면 얼굴이 조금씩 변할 수 있음 |
| Gemini 이미지 편집 | 사진 기반 편집이 빠르고 여러 장을 참조로 올릴 수 있음 | 얼굴 유사도는 장면마다 달라짐 |
| Midjourney | 인물 참조 기능(`--oref`, `--cref` 등)으로 같은 인물 유지, 그림 완성도 높음 | 버전마다 옵션 이름이 다름 |
| Stable Diffusion / ComfyUI (로컬) | IP-Adapter, LoRA 학습으로 일관성이 가장 높음 | 설정이 어렵고 컴퓨터 사양이 필요함 |

**추천**: 이미 쓰고 있는 도구 하나로 시작하세요. 그리고 **사실적 사진 보정보다 "일러스트 / 세미 리얼 만화체"로 통일**하는 걸 추천해요.
- 사진 속 얼굴을 매번 완벽히 닮게 만들기는 어렵지만, 만화체는 "같은 캐릭터"로 보이기 쉬워요.
- 60장을 만들어도 그림체가 일정해서 게임 화면이 훨씬 깔끔해요.

## 4. 같은 얼굴 유지 5단계 레시피

1. **기준 사진 3~6장** 준비: 정면, 살짝 옆, 웃는 얼굴, 무표정. 얼굴이 가려지지 않은 사진으로.
2. **스타일 문장을 하나 고정**하고 모든 요청에 똑같이 붙이기. 예:
   - 한국어: `세미 리얼 한국 웹툰 스타일, 부드러운 셀 셰이딩, 깔끔한 윤곽선, 따뜻한 조명`
   - 영어: `semi-realistic Korean webtoon style, soft cel shading, clean outlines, warm lighting`
3. **캐릭터 시트 1장 만들기**: "첨부한 사진 속 인물의 캐릭터 시트: 정면, 옆모습, 3/4 각도, 웃는 표정. 같은 얼굴 유지"
   → 마음에 드는 결과를 `assets/scenes_raw/_character_sheet.png`로 저장해 두고, **이후 모든 요청에 같이 첨부**.
4. **한 번에 한 장면만** 요청하고, 같은 대화/세션에서 이어서 만들기.
5. **결과 확인**: 얼굴(눈매·코·헤어), 손가락 개수, 글자가 섞이지 않았는지, 배경이 장면에 맞는지.

## 5. 프롬프트 템플릿

### 마스터 템플릿 (복사해서 {장면}만 바꾸세요)

```
첨부한 사진과 캐릭터 시트 속 인물(재민)을 얼굴 기준으로 사용하세요. 같은 얼굴과 같은 헤어스타일을 유지하세요.
장면: {장면 설명}
스타일: 세미 리얼 한국 웹툰 스타일, 부드러운 셀 셰이딩, 깔끔한 윤곽선, 따뜻한 조명
구도: 상반신 중심, 정사각형 1:1, 인물이 화면 중앙, 배경은 장면에 맞게 단순하게
금지: 글자, 로고, 워터마크, 다른 실존 인물의 얼굴, 과한 노출
```

이벤트 배너(가로형)는 구도 줄만 바꾸세요:
`구도: 가로 16:9, 인물은 왼쪽 또는 중앙, 장면의 소품이 잘 보이게`

### ⭐ 시작 화면: 비치볼에 맞는 재민이 (`lobby_beachball`)

```
장면: 햇살 좋은 해변(또는 펜션 마당)에서 날아온 비치볼에 머리를 맞고 눈이 휘둥그레진 재민.
공이 막 부딪힌 순간, 머리카락이 흔들리고 머리 위로 별 모양 효과, 만화적으로 과장하지만 다치는 느낌은 없이 코믹하게.
```

### ⭐ 오이고추 (`ev_pepper`)

```
장면: 집 현관에서 가방을 열자 오이고추가 우수수 쏟아져 나오는 순간, 당황해서 입이 벌어진 재민. 오이고추가 공중에 떠 있음.
```

## 6. 추천 작업 순서 (3시간 예시)

| 시간 | 할 일 |
|---|---|
| 0:00 ~ 0:30 | 도구 정하고, 스타일 문장 정하고, 캐릭터 시트 만들기 |
| 0:30 ~ 1:00 | `lobby_beachball`, `age_*` 3장 |
| 1:00 ~ 2:00 | 직업 15장 (한 장에 2~3번 시도) |

| 2:30 ~ 3:00 | 오이·비치볼·소시지·달걀·컵라면 등 대표 이벤트 |

한 장당 평균 2~3번 시도한다고 보면 우선순위 1+2번 50장에 3~4시간 정도 걸려요. 일단 **우선순위 1번만** 먼저 끝내도 게임이 크게 달라져요.

## 7. 파일로 저장하고 변환하기

1. 만든 이미지를 `assets/scenes_raw/` 폴더에 넣어요. **파일 이름은 위 표의 이름과 똑같이** (`lobby_beachball.png`, `job_doctor.jpg` 처럼). 확장자는 png, jpg, webp 모두 가능해요.
2. 저장소 맨 위 폴더에서 실행:

```bash
pip install pillow          # 처음 한 번만
python3 tools/prepare_scenes.py
```

3. 도구가 해 주는 일
   - 정사각형 이미지(`lobby_`, `age_`, `job_`, `end_`)는 가운데 기준으로 512×512로 자르고 압축
   - 이벤트 배너(`ev_`)는 가로 800px 이하로 줄임
   - `assets/scenes/manifest.js`를 갱신해서 게임이 이미지를 자동으로 찾게 함
   - 몇 장 만들었고 뭐가 남았는지 **진행 현황**을 보여 줌
   - 이름이 틀린 파일은 알려 주고 건너뜀
4. 용량은 전체 합쳐서 **8MB 이하**를 권장해요. 넘으면 도구가 알려 줘요.

진행 현황만 보고 싶으면 `python3 tools/prepare_scenes.py --status`.

## 8. 게임에 반영하기

- **내 컴퓨터에서 바로 확인**: `index.html`을 열면 `assets/scenes/`의 이미지를 바로 써요.
- **저장소에 올리기**: `assets/scenes/`(변환된 이미지)와 `assets/scenes/manifest.js`를 커밋해서 푸시.
- **공유 링크(아티팩트)에 반영**: "이미지 올렸어, 아티팩트에도 반영해 줘"라고 말해 주세요. 이미지 파일을 함께 올려서 링크에서도 보이게 해 드릴게요.
- **채팅으로 이미지를 보내도 돼요**: 이미지를 첨부하고 "이건 job_doctor, 이건 ev_pension" 처럼 이름을 알려 주시면 제가 변환해서 반영할게요.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 얼굴이 매번 달라져요 | 캐릭터 시트와 기준 사진을 **같이 첨부**하고, "첨부한 인물과 같은 얼굴"을 맨 앞에 쓰기. 같은 대화에서 이어서 요청 |
| 그림체가 장면마다 달라요 | 스타일 문장을 **글자 하나 안 바꾸고** 그대로 붙여 넣기 |
| 손가락이 이상해요 | 손이 안 보이는 구도(상반신, 손을 주머니에)로 바꾸기 |
| 이미지 안에 글자가 생겨요 | 프롬프트에 `글자, 로고, 워터마크 없음`을 추가 |
| 얼굴이 너무 작아요 | `얼굴이 화면의 절반 정도, 상반신 클로즈업`으로 요청 |
| 도구가 이름 없는 파일이라고 해요 | 파일 이름이 `tools/scene_keys.json`의 key와 **완전히 같은지** 확인 (대소문자 포함) |
| 게임에서 안 바뀌어요 | `python3 tools/prepare_scenes.py` 실행 후 브라우저 새로고침(캐시 삭제) |

## 10. 자주 묻는 질문

- **전부 안 만들면 어떻게 되나요?** 없는 이미지는 기존 사진과 이모지가 그대로 나와요. 오류는 없어요.
- **직업 이미지는 언제 나오나요?** 직업을 얻으면 그 직업 이미지가, 백수가 되면 `job_none`이 나와요. 다만 "지친 상태"나 "망한 상태"일 땐 기존 기분 사진이 우선이에요.
- **나이 이미지와 직업 이미지가 둘 다 있으면?** 직업 이미지가 우선이고, 직업이 없을 때 나이 이미지가 나와요.
- **엔딩 이미지는요?** 결과 화면에서 등급(S~D)에 맞는 이미지가 큰 사진 자리에 나와요.
